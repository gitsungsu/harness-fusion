# 후속 실전 평가 예제: 사내 작업 조회 API

이 파일은 후속 실제 모델 검증용 요구사항 예제이며, 구현 완료된 API가 아닙니다.

## 사전 준비

하네스 가상환경에 fastapi, httpx, pytest를 설치하고 검사 명령을
`["{python}", "-m", "pytest", "-q"]`로 지정한다. 외부 서버·운영 DB는 사용하지 않는다.

## 요구사항

- `src/app.py`의 FastAPI 앱을 작성한다.
- `GET /health`는 상태 코드 200과 `{"status":"ok"}`를 반환한다.
- `POST /tasks`는 title을 입력받고 201 및 id/title/done 값을 반환한다.
- title은 앞뒤 공백 제거 후 1–100자여야 한다. 잘못된 입력은 422로 거부한다.
- `GET /tasks`는 저장된 작업을 생성 순서대로 반환한다.
- `PATCH /tasks/{id}`는 done 값을 바꾼다. 없는 id는 404를 반환한다.
- SQLite를 사용하며 테스트는 임시 데이터베이스를 사용한다. 재접속 후에도 데이터가 유지돼야 한다.
- SQL 매개변수를 사용해 따옴표가 포함된 제목과 한글을 안전하게 저장한다.
- 테스트에서 앱을 직접 호출하며 실제 외부 네트워크 연결은 사용하지 않는다.
- README에 실행·검사 명령과 현재 인증 미구현 범위를 설명한다. 외부에 배포하지 않는다.

## 완료 기준

모든 엔드포인트 성공 사례, 검증 오류, 존재하지 않는 ID, 영속성, 한글과 따옴표 사례를
실행 가능한 테스트로 확인한다. Evaluator는 HTTP 상태·응답 구조·DB 격리까지 검토한다.
